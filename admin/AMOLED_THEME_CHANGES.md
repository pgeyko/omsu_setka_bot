# AMOLED Black Theme — Изменения

## 📋 Обзор

Админ-панель переведена на **AMOLED-чёрную тему** с **белым акцентом** для экономии батареи на OLED-экранах.

## 🎨 Цветовая палитра

### AMOLED (по умолчанию)
```css
--bg: #000000              /* Истинный чёрный */
--bg-card: #080808         /* Едва заметное отличие */
--bg-elevated: #121212     /* Для hover/active */

--accent: #ffffff          /* Белый акцент */
--accent-hover: #d8d8d8

--text: #f5f5f5            /* Почти белый, мягче для глаз */
--text-muted: #9e9e9e

--danger: #ff5252          /* Ярче для контраста */
--success: #00e676
--warning: #ffab40
```

### Light theme (переключатель)
Сохранена оригинальная светлая тема с фиолетовым акцентом.

## 🔧 Технические изменения

### 1. **Файлы изменены**
- `src/styles/variables.css` — полная переработка
- `src/styles/global.css` — обновление всех компонентов

### 2. **Убран glassmorphism**
- `--glass-blur: 0px` для AMOLED
- `backdrop-filter` отключён через `@media (prefers-contrast: high)`
- Экономия GPU ресурсов

### 3. **Контраст**
- Текст: 17:1 (WCAG AAA)
- Акцент: максимальный на чёрном фоне
- Семантические цвета ярче для читаемости

### 4. **Кнопки**
- `.btn-primary`: белый фон + чёрный текст
- `.btn-danger`: красный фон + белый текст
- Светлая тема: переопределение через `[data-theme="light"]`

## 📱 Преимущества

### Для пользователей
- ✅ **Экономия батареи** — пиксели выключены на чёрном фоне
- ✅ **Читаемость** — высокий контраст
- ✅ **Стиль** — минималистичный монохромный дизайн
- ✅ **Комфорт** — текст не режет глаза (не 100% белый)

### Для производительности
- ✅ **GPU** — нет backdrop-filter
- ✅ **CSS** — проще градиенты и тени
- ✅ **Размер** — CSS сжат лучше (1.99 KB vs 1.92 KB)

##  Переключение тем

Кнопка в sidebar (иконка ☀️/):
- **По умолчанию**: AMOLED (тёмная)
- **Переключение**: Light (светлая)
- **Хранение**: localStorage (`groupbot-theme`)

## 💡 Рекомендации

### Для AMOLED экранов:
- Использовать тёмную тему по умолчанию ✅
- Избегать больших белых областей
- Яркие акценты для важных элементов

### Для LCD/IPS:
- Светлая тема днём
- Тёмная тема ночью
